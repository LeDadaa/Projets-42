# NetPractice

## Description
 
NetPractice's main goal is to introduce and strengthen fundamental networking concepts through exercices.
With these exercises, students develop a clear understanding of how computer networks 
function and learn how routing decisions impact the connection between multiple devices.
This project allowed the study and practice of the following networking concepts:
- TCP/IP addressing (IPv4)
- Subnet masks and CIDR notation
- Network and broadcast addresses
- Default gateways
- Basic routing principles
- Routers and switches
- Communication between different subnets
- OSI model layers (especially Network and Data Link layers)

## Instructions

To launch NetPractice, just download the raw file given to you and run index.html
